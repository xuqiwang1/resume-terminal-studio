Local-first resume workbench

AI agents can write. You approve the patch.

Resume Studio is an Electron + React desktop app that turns terminal AI agents into controlled resume collaborators: they read local materials, submit reviewed edits through MCP, and only write after you accept.

See the flow ↓ What was built

Why this exists

普通 AI 简历工具追求“一键生成”。Resume Studio 解决的是“AI 参与写作时，谁拥有最后写入权”。

简历包含真实经历、敏感材料和高风险表述。这个项目把 AI 能力放进一个可见、可审、可回退的本地工作台，而不是让模型在黑箱里直接覆盖个人简历。

System, not a generator

一个完整做出来的桌面端 AI 协作系统。

01

Electron desktop app

真实桌面入口，管理本地工作区、桥接运行时、A4 预览、样式面板、历史和 PDF 导出。

02

React resume editor

结构化简历数据、模板样式、字段选择、内联样式和打印视图分离。

03

Local bridge

本地 API 负责保存、打开、历史归档、运行状态、导出和安全工作区边界。

04

MCP server

让 Codex、Claude Code、Antigravity CLI 用标准工具读取简历并提交 patch。

05

Material ingestion

把 markdown、文本版 PDF、xlsx 表格抽成可读材料，agent 基于事实而不是空提示词写作。

Human-reviewed AI workflow

从素材到 PDF，中间每一步都留在你的控制范围内。

  1. materials 真实材料进入本地 workspace。

    实习证明、项目笔记、表格数据不需要上传到云端。

  2. ingest 抽取成 agent 可读 markdown。

    PDF / xlsx / md 被整理成清晰文本，减少模型乱猜。

  3. MCP 终端 agent 读取简历和材料。

    agent 在 Codex、Claude Code 或 agy 里工作，而不是被塞进网页表单。

  4. patch propose_edit 只进入待确认槽。

    AI 不能直接覆盖正文，APP 展示 diff 和预览变化。

  5. export 接受后写入，保留历史，再导出 PDF。

    重塑简历前自动归档，结果可回退。

Different from AI resume builders

不是一键生成器。

一键生成工具把结果当成终点；Resume Studio 把协作过程当成产品。

  • 普通工具：上传简历 → AI 改写 → 直接接受结果。
  • Resume Studio：本地材料 → agent 提案 → diff 审核 → 人工确认 → PDF。
  • 核心差异：AI 可以大胆写，但写入权始终在用户手里。

Development highlights

开发重点不是“页面好看”，而是把不确定的 AI 输出放进确定的工程边界。

Pending patch as trust primitive

正文类改写走 `propose_edit`，先暂存，展示 diff，确认后才写入 active resume。

Workspace privacy boundary

真实简历、materials、history、运行日志默认在本机，并被 GitHub 上传边界排除。

Desktop and web separated

APP 只做工具本体；官网只做项目介绍，避免把 marketing 页面塞进工作台。

Agent support

支持现有终端 AI 工作流，而不是替代它们。

Resume Studio 暴露本地 MCP server。agent 可以调用 `get_resume`、`propose_edit`、 `get_pending_patch`、`confirm_patch`、`reject_patch` 等工具。
