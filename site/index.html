The problem

Most AI resume tools optimize for instant generation. Real resumes need auditability.

Your resume contains private facts, sensitive timelines, and high-stakes claims. Resume Studio treats AI as a collaborator that proposes changes, not a silent writer with direct access to your final document.

01

Desktop workbench

A real Electron app for editing, previewing, styling, saving, restoring, and exporting a resume.

02

Local materials

Extract notes, PDFs, and spreadsheets into clean local markdown for agents to read.

03

MCP agent bridge

Codex, Claude Code, and Antigravity CLI can inspect state and submit edits through standard tools.

04

Human-reviewed patch flow

Every substantive rewrite enters a pending diff. Accept it, reject it, or keep iterating before it touches the resume.

Workflow

Materials → agent reads → propose_edit → diff → accept or reject → export PDF.

  1. 01Drop materials into the local workspace.
  2. 02Run ingest to create agent-readable markdown.
  3. 03Ask a terminal agent to inspect context and draft changes.
  4. 04Review the pending patch inside the desktop app.
  5. 05Export a clean A4 PDF after approval.

Privacy boundary

Resume data and source materials stay local by default.

Runtime workspace files, extracted materials, history snapshots, and personal resumes are intentionally excluded from the public repository. The open-source project ships source code and non-personal templates.

Agent support

Designed for terminal-native AI workflows.

Resume Studio does not hide the agent inside a web form. It exposes a local MCP server so existing developer tools can read resume state, inspect materials, and submit reviewed changes.
