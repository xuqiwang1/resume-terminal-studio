# 简历短版项目描述

## 本地优先简历编辑工作台 Resume Studio

**AI 产品设计 / 独立开发｜2026.05 - 2026.08**

- 针对 AI 改写简历过程不透明、用户难以核验改动依据与回退成本高的问题，独立设计并开发本地优先的简历编辑工作台，将 A4 实时排版预览、桌面端应用、本地服务、模型上下文协议（MCP）与终端智能体无缝串联成可审核的协作闭环。
- 主导设计“AI 提议、人工把关、确认写入”的待确认补丁机制：终端智能体（如 Codex、Claude Code、Antigravity 等）仅能通过标准协议提交修改建议，工作台实时展示改动前后的差异对比与材料溯源，由用户自主确认后写入，杜绝黑箱无感覆写。
- 研发本地多格式素材摄入链路，支持将 Markdown、纯文本、文字版 PDF 及 Excel 数据表自动提取为结构化素材，使智能体能基于真实经历与数据事实精准撰写简历内容。
- 打造 4 款精选简历模板矩阵（专业商务、经典求职、现代风尚、商务精英），实现 A4 单页智能自适应算法、页面溢出精准归因、模块拖拽排序、富文本链接与引导加粗等专业级排版能力。
- 设计完善的本地防丢稿机制：在接受 AI 改动、切换模板、恢复历史版本时均自动生成本地快照存档，确保多版本与多岗位迭代过程安全可控。
